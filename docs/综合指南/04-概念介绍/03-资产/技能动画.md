# 一、技能动画的定义

技能动画是指为实体设计和实现的各种战斗动作的动画资产

# 二、角色技能动画

## 1.角色技能动画的特点

角色技能动画必须依赖角色实体，每个技能动画播放必须存在明确的角色实体做载体。

角色技能动画的播放依赖自定义技能的释放。

目前角色技能动画按照技能使用特色，分成了*普通攻击*、*持续引导*、*位移*三类。

## 2.角色技能动画的引用

在技能编辑时，奇匠可以通过引用角色技能动画，定义技能释放后的角色的动画演出效果。

具体引用方式，请参考[技能](../04-高级概念/技能.md)

# 三、造物技能动画

## 1.造物技能动画的特点

造物技能动画必须依赖造物实体，每个技能动画播放必须存在明确的造物实体做载体。

造物技能动画的播放依赖自定义技能的释放。

目前造物技能动画按照技能使用特色，分成了*普通、持续*两类。

## 2.造物技能动画的引用

在技能编辑时，奇匠可以通过引用造物技能动画，定义技能释放后的造物的动画演出效果。

具体引用编辑方式，请参考[技能](../04-高级概念/技能.md)
