# 一、功能是什么

功能是对*物件*和*造物*所具有属性以及满足某种特定需求能力的描述

包含基础信息、特化配置、通用组件和节点图

另外玩家和角色也拥有其中的部分功能

详见[玩家](01-单位/玩家.md)[角色](01-单位/角色.md)

# 二、功能的编辑

选中元件或实体后，即可在右侧的详情面板查看及编辑对应的功能
