# 一、计分板的功能

![图片](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhesro0hyn5k/3cdff313-857d-470a-8d82-f9bdbf7b8959.png)

关卡运行时，用于显示玩家自定义变量，并可以根据自定义变量进行排名的信息展示界面。

# **二、计分板的编辑**

![图片](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhesro0hyn5k/738adffa-1ae7-45b2-8a9e-6654427a96a4.png)

| 配置参数 | 说明 |
| --- | --- |
| *排序* | 提供数值升序和降序 |
| *类型* | 个人、阵营，类型的选择将影响余下配置参数的配置内容 |
