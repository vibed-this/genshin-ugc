# 节点图编辑

## 节点图说明

### 功能简述

**节点图：**是指由创作者自行编写的自定义逻辑，用于实现游戏中的逻辑功能效果

**节点图类型：**当前分为【实体节点图】、【状态节点图】、【职业节点图】、【道具节点图】、【布尔过滤器节点图】、【整数过滤器节点图】、【技能节点图】七种类型

> 【实体节点图】、【状态节点图】、【职业节点图】和【道具节点图】的逻辑在服务端运行，因此统称为****服务器节点图****；【布尔过滤器节点图】、【整数过滤器节点图】和【技能节点图】都是在玩家本地（客户端）运行，因此统称为****本地节点图（客户端节点图）****

以上类型的区分将影响节点图中监听/执行规则、具体节点配置和可挂载对象

## 节点图编写

### 节点图编写思路

节点图的有关键三要素**【事件】**、**【条件】**、**【结果】**，通过合理连线串联这三者，可构成完整的节点图（实现逻辑功能），以下为通用拆解思路：

> 1.明确功能实现的触发条件，即****【什么事件导致】****2.功能执行时是否根据条件判断有不同分支结果，即****【什么条件下触发对应的后续结果】****3.确认功能执行后的效果，即****【最终实现什么效果】****

***需要额外说明的是：以上编写思路为适用于绝大多数节点图的通用拆解思路，部分节点图类型（如：本地过滤器节点图等）不一定严格由【事件】、【条件】、【结果】三部分组成，根据实际情况选择使用即可*

### 操作流程

> 1.根据所需制作的节点图类型选择对应的节点图页面（教程中以【服务器节点图-实体节点图】为例进行演示）![图片](https://act-webstatic.mihoyo.com/ugc-tutorial/course/cn/zh-cn/mhzu1vi0s3ms/bef1006e-8e53-420c-a9e1-fcf1b8f1eb56.png) 2.在页面中，点击鼠标右键展开选项列表>>>选择【创建节点图】>>>即可新建一个节点图并打开对应的节点图编辑界面![图片](https://act-webstatic.mihoyo.com/ugc-tutorial/course/cn/zh-cn/mhzu1vi0s3ms/e1aa451d-8c88-4c49-8b5c-bb4f70e4155c.png) 3.在节点图编辑界面中，点击鼠标右键展开选项列表（节点库）>>>选择对应的节点即可创建![图片](https://act-webstatic.mihoyo.com/ugc-tutorial/course/cn/zh-cn/mhzu1vi0s3ms/4ff0d5eb-aa6c-44cf-bb5b-5329639f060e.png) 4.完成基础的节点图搭建后>>>点击保存>>>即完成了节点图编写示例中功能为：和某物体进行交互后，如果交互选项为1，则销毁该物体；如果选项为2，则无效果![图片](https://act-webstatic.mihoyo.com/ugc-tutorial/course/cn/zh-cn/mhzu1vi0s3ms/ae9faee3-a947-428e-acf2-44317ce40c2f.png)
