# 一、编辑模块切换

![图片](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhexhcr1qjh2/37499681-b34a-4beb-b99e-9731dcd4eed7.png)

通过左侧边栏可切换编辑模块，从上至下分别是：

玩家与职业编辑：[玩家](../04-概念介绍/01-单位/玩家.md)[角色](../04-概念介绍/01-单位/角色.md)[职业](../04-概念介绍/04-高级概念/职业.md)单位状态编辑：[单位状态](../04-概念介绍/04-高级概念/单位状态.md)技能编辑：[技能](../04-概念介绍/04-高级概念/技能.md)本地投射物编辑：[本地投射物](../04-概念介绍/01-单位/本地投射物.md)道具编辑：[道具](../04-概念介绍/04-高级概念/04-资源系统/道具.md)

# 二、新建与保存

![图片](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhexhcr1qjh2/c26f00a2-948b-494b-8827-30ea00d3c865.png)

通过资产栏的新建按钮可新建当前选中编辑模块对应内容。

![图片](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhexhcr1qjh2/0f6d7301-77f4-4cee-9561-3e7a0f430426.png)

角色与职业编辑模块的内容修改后会自动保存，而单位状态、技能、本地投射物和道具的内容修改后需要手动进行保存。资产栏内对应内容出现黄色感叹号标识（如图所示）代表当前内容有未保存内容，可通过底部的保存按钮（如图所示）进行保存或另存为新内容。
